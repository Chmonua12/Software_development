## Идея проекта

ArtConnect адаптирует задание про dating-бота под арт-комьюнити. Вместо обычных анкет знакомств пользователь создаёт творческую анкету: имя или псевдоним, возраст, город, описание творчества, аватарку, до 5 работ, направления искусства и ссылки на соцсети.

Лента показывает художников по рейтингу, а пользователь может:

- поставить **лайк для общения** — при взаимном лайке появляется мэтч;
- добавить анкету **в избранное** — без мэтча, как сохранение интересного художника;
- пропустить анкету;
- перейти по ссылке на Telegram, Instagram, VK, Behance или другую площадку;
- смотреть топ-10 художников.

## Что реализовано по этапам практики

### Этап 1: Планирование и проектирование

- Описана архитектура в `ARCHITECTURE.md`.
- Подготовлены диаграммы в `docs/`:
  - контекст системы;
  - компонентная схема;
  - поток регистрации;
  - лента, лайки и события;
  - pipeline пересчёта рейтинга;
  - DBML-схема данных.
- Создан репозиторий и структура проекта.

### Этап 2: Базовая функциональность

- Telegram Bot API через `aiogram`.
- `/start` регистрирует пользователя по `telegram_id`.
- Пошаговое заполнение анкеты:
  - имя или псевдоним;
  - возраст;
  - город;
  - описание творчества;
  - аватарка;
  - до 5 изображений работ;
  - интересы;
  - соцсети.
- `/profile`, `/edit`, `/delete`, `/cancel`, `/help`.
- Данные сохраняются в SQLite `data/bot.sqlite3` для локального запуска.

### Этап 3: Анкеты и ранжирование

- CRUD-логика анкет:
  - создание и обновление через `/start`;
  - просмотр через `/profile`;
  - частичное редактирование через `/edit`;
  - мягкое удаление через `/delete`.
- Лента `/feed` показывает другие анкеты.
- Реализована трёхуровневая рейтинговая модель:
  - **Уровень 1** — качество анкеты: био, город, возраст, аватарка, количество работ, интересы, соцсети, бонус за основной Telegram.
  - **Уровень 2** — поведение: лайки, пропуски, просмотры, мэтчи, переходы по соцсетям.
  - **Уровень 3** — комбинированный рейтинг: `0.4 * primary + 0.6 * behavior + referral_bonus`.
- Redis/in-memory кэш предранжированных очередей анкет: `feed_queue:{profile_id}`, пачка до 10 анкет.
- Redis-list используется как лёгкая MQ-очередь событий: `mq:interaction_events`.

### Этап 4: Дополнительные функции

- Celery-задачи в `bot/tasks.py`:
  - полный пересчёт рейтингов;
  - прогрев кэша топа;
  - обработка событий взаимодействия.
- Локальный fallback-планировщик для демо без отдельного Celery worker.
- Redis-кэш:
  - очередь ленты;
  - топ-10 на 5 минут;
  - очередь событий.
- Minio/S3:
  - `docker-compose.yml` поднимает Minio;
  - если `ENABLE_MINIO=true`, бот загружает фото в Minio;
  - если Minio выключен, используется Telegram `file_id`, чтобы бот работал локально без S3.
- Метрики Prometheus в `bot/metrics.py`.
- JSON-логи взаимодействий в `logs/`.
- Smoke-тесты в `test_bot_setup.py`.

## Команды бота

- `/start` — регистрация или обновление анкеты.
- `/profile` — показать свою анкету.
- `/edit` — изменить имя, город, описание или интересы.
- `/delete` — скрыть анкету из ленты.
- `/feed` — открыть ленту художников.
- `/favorites` — показать избранные анкеты.
- `/top` — топ-10 художников.
- `/recalc` — ручной пересчёт рейтингов для администратора.
- `/metrics` — метрики для администратора.
- `/cancel` — отменить текущее действие.

## Быстрый запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
python run_bot.py
```

Redis и Minio для полного локального стенда:

```powershell
docker compose up -d
$env:REDIS_URL="redis://127.0.0.1:6379/0"
$env:ENABLE_MINIO="true"
python run_bot.py
```

Celery worker и beat:

```powershell
celery -A bot.tasks:celery_app worker --loglevel=info
celery -A bot.tasks:celery_app beat --loglevel=info
```

Проверка проекта:

```powershell
$env:PYTHONIOENCODING="utf-8"
python test_bot_setup.py
python -m py_compile bot\main.py bot\storage.py bot\feed.py bot\feed_cache.py bot\rating.py bot\tasks.py bot\metrics.py bot\minio_client.py
```

## Почему это соответствует заданию

Практика требует dating-приложение с анкетами, рейтингом, Redis-кэшированием, очередью событий, отложенными задачами, S3-хранилищем, метриками и логированием. В ArtConnect эти требования сохранены, но предметная область изменена на арт-комьюнити: лайки становятся способом общения или сохранения работ, поведенческий рейтинг учитывает интерес к портфолио и переходы в соцсети, а топ показывает популярных художников.
